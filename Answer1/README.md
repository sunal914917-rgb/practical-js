# Question 1: Your First JavaScript Script

## Aim
To write and execute the first JavaScript program using Node.js.

## Theory
JavaScript is a high-level programming language used to make web pages interactive and dynamic.

It can also run outside the browser using Node.js.

The `console.log()` method is used to display messages or output in the console.

## Code Explanation
1. `console.log()` is used to print output.
2. Text is written inside double quotation marks.
3. Each `console.log()` statement prints a separate message.

## JavaScript Code
```javascript
console.log("Hello, World!");
console.log("Welcome to JavaScript.");
```

## Output
```text
Hello, World!
Welcome to JavaScript.
```

## Conclusion
Successfully created and executed the first JavaScript program using Node.js and the `console.log()` method.
