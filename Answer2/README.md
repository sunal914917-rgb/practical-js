# Question 2: Operators, Type Conversion and a Calculator

## Aim
To understand JavaScript operators, type conversion and perform basic arithmetic operations using a simple calculator.

## Theory

### 1. Operators
Operators are symbols used to perform operations on variables and values.

**Arithmetic Operators:**
- `+` Addition
- `-` Subtraction
- `*` Multiplication
- `/` Division
- `%` Modulus

**Comparison Operators:**
- `>` Greater than
- `<` Less than
- `==` Equal to
- `===` Strict equality

**Logical Operators:**
- `&&` Logical AND
- `||` Logical OR
- `!` Logical NOT

### 2. Type Conversion
Type conversion means changing a value from one data type to another.

JavaScript provides functions such as:
- `Number()` – Converts a value into a number.
- `String()` – Converts a value into a string.
- `Boolean()` – Converts a value into a boolean.

The `typeof` operator is used to check the data type of a value.

### 3. Calculator
A simple calculator performs basic mathematical operations such as addition, subtraction, multiplication and division.
