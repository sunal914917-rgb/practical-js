# Question 3: Conditions and Loops

## Aim
To understand and implement conditional statements and loops in JavaScript.

## Theory

### 1. Conditional Statements
Conditional statements are used to execute different blocks of code based on conditions.

- **if:** Executes code when a condition is true.
- **else if:** Checks another condition if the previous condition is false.
- **else:** Executes when all previous conditions are false.
- **switch:** Executes a matching case based on a given expression.

### 2. Loops
Loops are used to execute a block of code repeatedly.

- **for loop:** Used when the number of iterations is known.
- **while loop:** Repeats code as long as the condition is true.

### 3. Break Statement
The `break` statement terminates a loop or switch statement.

### 4. Increment Operator
The `++` operator increases a variable's value by one.
